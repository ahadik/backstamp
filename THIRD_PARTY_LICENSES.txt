2. EXTERNAL SERVICES
================================================================================

The following third-party APIs are called at runtime. They are not bundled with
the application. Users must create accounts and agree to the respective terms
of service independently. API keys are stored locally in the macOS Keychain.

--------------------------------------------------------------------------------
Anthropic Claude API
--------------------------------------------------------------------------------
Website: https://www.anthropic.com
Used for: AI-assisted metadata editing ("VibeTag" feature)
Terms:    https://www.anthropic.com/legal/consumer-terms

Using the VibeTag feature requires a valid Anthropic API key and is subject to
Anthropic's usage-based pricing. Photo filenames and user-written metadata
prompts are sent to Anthropic's servers for processing.

--------------------------------------------------------------------------------
Mapbox APIs
--------------------------------------------------------------------------------
Website: https://www.mapbox.com
Used for: Map rendering, geocoding, GPX track thumbnails, location search
Terms:    https://www.mapbox.com/legal/tos

Using map and location features requires a valid Mapbox access token and is
subject to Mapbox's usage-based pricing.

--------------------------------------------------------------------------------
Google Places API
--------------------------------------------------------------------------------
Website: https://developers.google.com/maps/documentation/places/web-service
Used for: Location autocomplete search in the inspector panel
Terms:    https://developers.google.com/maps/terms-20180207

Using location search features requires a valid Google Maps API key and is
subject to Google's usage-based pricing.
